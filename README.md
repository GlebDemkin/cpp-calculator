# Calculator

Учебный консольный калькулятор на C++17 для Windows с функциями из DLL.

## Файлы и классы

- `src/` — реализации, `include/calculator/` — заголовки.
- `Application` — ввод, вывод, запуск и обработка исключений.
- `Lexer` — выделение чисел, имён, операций и скобок.
- `Parser` — разбор выражения и вычисление результата.
- `PluginManager` — загрузка DLL и вызов функций по имени.
- `SharedLibrary` — владение загруженной библиотекой и её освобождение.
- `plugins/` — реализации `sin`, `ln` и `sqrt`.
- `plugin_api.hpp` — описание плагина: имя и указатель на функцию `double(double)`.
- `CMakeLists.txt` — сборка приложения и трёх DLL.

## Использование

Поддерживаются `+`, `-`, `*`, `/`, `^`, унарные знаки, скобки и вложенные вызовы функций. Числа имеют тип `double`, дробный разделитель — точка. Показатель степени целый, для вычисления используется `std::pow`. `sin` принимает градусы, `ln(x)` требует `x > 0`, `sqrt(x)` — `x >= 0`.

Примеры: `16 + 4 * (3 - 1)` → `24`; `2^4 + sin(90)` → `17`.

Программа принимает выражения до команды `exit`. После ошибки можно ввести следующее выражение.

При запуске загружаются DLL из папки `plugins` рядом с exe. Математическое имя берётся из структуры, которую возвращает экспортированная функция `calculator_plugin`. Имя файла DLL произвольное. Без плагинов работает арифметика. Для добавления функции достаточно положить новую DLL в эту папку и перезапустить приложение.

Приложение и плагины используют один общий заголовок и должны собираться одним MSVC x64, с одинаковой библиотекой среды C++ и в одной конфигурации (Debug или Release). CMake задаёт общие настройки. Исключения из математических функций перехватываются в `Application`.

## Сборка и запуск

Нужны CMake, MSVC x64 и Windows SDK. Открой корень проекта в VS Code. Команды из терминала в этой папке для стандартного генератора Visual Studio:

```powershell
cmake -S . -B build -A x64
cmake --build build --config Debug
```

После первой сборки запуск из того же терминала:

```powershell
.\build\bin\Debug\calc.exe
```

DLL будут находиться в `build/bin/Debug/plugins`. CMake размещает их там автоматически. Для следующих запусков достаточно команды запуска, после изменения исходников сначала нужно повторить сборку. Для Release нужно заменить `Debug` на `Release` в команде сборки и пути к exe.
